# Noise Complaint

Playable builds of Noise Complaint, an upstairs-neighbor noise simulator.

This repository holds compiled builds only. Game source is not published here.

## Play

[Play the latest build](https://bryee10.github.io/noise_complaint_builds/)

GitHub Pages serves the `docs/` folder on `main`. The landing page sends players straight to the newest build.

## Versions

- **Latest:** [v0.2 Godot rebuild](https://bryee10.github.io/noise_complaint_builds/v0.2/) (`docs/v0.2/`) — Godot 4.7.2 web export. The first load downloads about 60-110 MB; Wi-Fi is recommended.
- **Older:** [v0.1 browser prototype](https://bryee10.github.io/noise_complaint_builds/prototype-v1/) (`docs/prototype-v1/`) — self-contained browser build
